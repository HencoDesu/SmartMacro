# Nocturne — токены для порта в Avalonia

Источник: design-system проект Nocturne (`60a10b6f-f6b0-4e7a-b3ed-d9a424d5d17b`), файл `styles.css`.
Здесь только то, что переносится в `ResourceDictionary`; CSS-компоненты (`.btn`, `.card`, …) в Avalonia не переносятся как есть — вместо них `ControlTheme`.

## Рампы (OKLCH, единая шкала светлоты — одинаковый шаг = одинаковый визуальный вес)

**neutral**: `100 #f3f5fe` · `200 #e4e7f5` · `300 #cfd3e5` · `400 #b2b6ca` · `500 #9397ab` · `600 #75798c` · `700 #595d6c` · `800 #3f424d` · `900 #292b31`

**accent**: `100 #f5f4ff` · `200 #e7e5fe` · `300 #d2cefd` · `400 #b5abfc` · `500 #968ae0` · `600 #796cbf` · `700 #5d5294` · `800 #423a6a` · `900 #2b2741`

`accent-2` в моно-схеме читается как accent — отдельной роли не заводить.

## Метрики

- Шрифт: Inter (heading и body), вес заголовков **500** — не жирнее.
- Плотность 0.7×: `space` = `2.8 / 5.6 / 8.4 / 11.2 / 16.8 / 22.4` px (шаги 1/2/3/4/6/8).
- Радиусы: `sm 4` · `md 8` · `lg 14`.
- Тени: `sm` = кромка `0 0 0 1px #3f424d`; `md` = кромка `#595d6c` + `0 6px 18px rgba(0,0,0,.55)`; `lg` = кромка `#9397ab` + `0 16px 40px rgba(0,0,0,.65)`.

## Правила, которые легко нарушить при порте

- **Акцент — линия и свечение, не заливка.** Первичная кнопка = обводка акцентом по прозрачному, а не залитый прямоугольник. Исключений в интерфейсе нет (заливка акцентом разрешена только в deck/landing шаблонах, которых у нас нет).
- **Ни чистого чёрного, ни чистого белого** — всё из рамп. Исключение: тени (там чернота как среда, а не цвет).
- **Заголовки не жирнее 500** — иерархия размером и воздухом.
- **Состояния из рампы акцента**: hover — тинт акцента ~12%, pressed — ~22% (или шаг рампы), focus — `2px` обводка акцентом с отступом `2px`. Дефолтную системную обводку фокуса не оставлять.
- **Тени не штабелировать** — на тёмном фоне высота это кромка плюс мягкая тень.
- Акцент к фону даёт ≥3:1 — годится для иконок, крупного текста и хрома, **не для основного текста**. Для абзацного текста акцентом — `accent-300`.

## Значения, взятые макетом сверх системы

Макет местами берёт цвета мимо рамп (фон окна `#0d0e16`, панели `#131420` / `#191b28` / `#1c1e2a`, разделители `#262939` / `#2b2e3d`, «склад» янтарный `#dbb277` на `rgba(219,178,119,.12)`, ошибка `#dd8189`). Это осознанные локальные оттенки под плотный инструмент; переносить их как именованные ресурсы (`SurfaceSunken`, `SurfaceRaised`, `Warning`, `Danger`), а не хардкодить по месту.
